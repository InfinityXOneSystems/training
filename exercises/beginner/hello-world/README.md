# Hello World Exercise

## 🎯 Objective

Create your first program that prints "Hello, World!" to the console.

## 📝 Description

This is a classic first exercise in programming. You'll create a simple program that outputs text to demonstrate basic syntax and program structure.

## ✅ Requirements

Write a program that:
1. Prints exactly: `Hello, World!`
2. Outputs to the standard console/terminal
3. Runs without errors

## 🚀 Getting Started

Choose your programming language and create your solution:

### Python
```python
# hello.py
# Your code here
```

### JavaScript
```javascript
// hello.js
// Your code here
```

### Java
```java
// Hello.java
// Your code here
```

### Go
```go
// hello.go
// Your code here
```

## 🧪 Testing Your Solution

### Python
```bash
python hello.py
```

### JavaScript
```bash
node hello.js
```

### Java
```bash
javac Hello.java
java Hello
```

### Go
```bash
go run hello.go
```

## 💡 Expected Output

```
Hello, World!
```

## 🎓 Learning Goals

- Understand basic program structure
- Learn how to output text
- Get familiar with running programs in your chosen language

## 📚 Next Steps

Once you complete this exercise, try:
- Printing your name instead
- Printing multiple lines
- Taking user input and greeting them by name

Good luck! 🚀
